# 📝 Editor de Texto em C++ (SDL2)

## 📖 Descrição
Este projeto é um editor de texto desenvolvido em **C++**, com funcionalidades semelhantes a um bloco de notas simples. Ele utiliza a biblioteca **SDL2** para criação da interface gráfica e manipulação de eventos, permitindo renderizar texto em tempo real.

O objetivo principal do projeto é estudar conceitos de desenvolvimento gráfico, manipulação de entrada do usuário e organização de código em C++.

---

## ✨ Funcionalidades

- 📄 Edição de texto em tempo real
- ⌨️ Captura de entrada via teclado
- 🖥️ Renderização gráfica utilizando SDL2
- 📜 Navegação básica no texto
- 🧠 Estrutura de buffer de texto
- ⚡ Interface leve e simples

---

## 🛠️ Tecnologias

- **C++**
- **SDL2**
- **SDL2_ttf**
- **Makefile**
